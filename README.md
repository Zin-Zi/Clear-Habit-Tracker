# Clear Habit Tracker

A minimalist, 100% offline Android habit tracker for NoFap and personal streaks. Built with Kotlin and Jetpack Compose.

## Features

- Track daily habits and streaks
- Clean, minimalist UI with FAB and Glassmorphism design
- 100% offline - no internet required
- Built with Kotlin and Jetpack Compose

## Tech Stack

- Kotlin
- Jetpack Compose
- Capacitor (for WebView integration)
